一点好玩，一点自由。

这里是沧屿的小小游戏屋，收录了五款玩法各不相同的独立小游戏。可以直接在浏览器里试玩，也可以下载后离线玩。

**[进入游戏屋](https://lztyblog.github.io/Cangyu-game/) · [查看游戏库](https://lztyblog.github.io/Cangyu-game/#games)**

目前所有游戏均可免费试玩，无需注册。主要按电脑键盘操作设计，部分游戏提供简易触屏按钮，建议先在电脑上体验。

## 怎么开始玩

### 在线试玩

进入游戏屋，选择一款游戏，点击「在线试玩」。试玩页上方可以返回游戏屋，也可以下载对应的离线版。

各游戏内都有自己的操作说明，按键并不完全相同；第一次玩时先看看开场提示。

### 下载后离线玩

1. 在游戏卡片上点击「下载」，保存对应的 ZIP 压缩包。
2. 右键选择「全部解压」，保留解压后的完整目录。
3. 用浏览器打开解压目录中的 `index.html`。

不要直接在压缩包内运行，也不要只把 `index.html` 单独拿出来。离线游戏文件包含所需素材，无需另行安装启动器。

## 新上架：《借招》v0.5

**拆下他的招，把节奏打回来。**

技能直接融入轻重击连招。看准时机精准拆招，不仅能积攒大招，还能把对手的特性借到下一次技能里。

- **分段教学**：十三项课程，每项实际成功两次后开启闯关；已学课程可以复习。
- **六关擂台**：从基础实战开始，逐步面对控距、连拳、虚晃换边与余震封路，最后挑战三式合流的冠军。
- **训练场**：随时练习连招、拆招或固定招式，失败后也能针对性练习，再返回原关卡。
- **自由战斗**：通关六关后解锁，可以选择对手、难度和战斗阶段。

### 基本操作

| 按键 | 操作 |
| --- | --- |
| `A / D` 或左右方向键 | 移动 |
| `空格` | 跳跃 |
| `J / K` | 轻击 / 重击，按顺序组合成连招 |
| `I` | 按住防御；即将受击前瞬间按下可精准拆招 |
| `L / Shift` | 闪步 |
| `U` | 大招能量蓄满后，靠近对手释放 |
| `H / Esc` | 招式手册 / 暂停 |

还可以挑空后接空中连段。看到命中再衔接下一击，终结技之后留意收势与防守。

### v0.5 调整

- 普通三连基础伤害降到 **13**，完整技能连招基础伤害为 **35–55**，鼓励用普攻试探、用连招打伤害。
- 第一关对手满血与玩家相同，之后逐关提高；标准模式六关敌方生命为 **180 / 234 / 306 / 396 / 504 / 630**，攻击伤害也逐关增加。
- 三连和技能终结后需要收招，对手能在自然空当接防、反击，并应对重复使用的终结技。
- 兼容 v0.4 的教学、通关与进度导出文件；已经通关的玩家可以直接重打六关。

## 存档与进度

游戏进度主要保存在当前浏览器中，各款游戏使用独立存档。换电脑、换浏览器、使用无痕模式或清理浏览器数据，都可能导致原进度无法读取。

《留在这里的我》《请向我开炮》和《借招》支持在游戏内导出、导入 JSON 进度文件。需要换设备，或从本地离线版转到网页继续玩时，先导出备份，再在目标环境导入。

在线版和本地离线版通常各自保存进度，不会自动同步。

## 试玩与下载统计

网站接入了[游戏统计页面](https://cangyu-playroom-statistics.sharpcurry64.chatgpt.site)，可以查看访问、开始游玩和下载入口点击等汇总数据。

- **试玩玩家**按匿名浏览器标识去重，不等于实名人数。
- **开始游玩**在实际操作游戏时记录，只打开试玩页不会直接计为游玩。
- **下载点击**表示点击 ZIP 下载入口，不代表文件已经下载完成。
- **离线游玩**不发送统计，统计服务暂时不可用也不影响游戏运行。

## 反馈问题或想法

欢迎反馈卡关、操作不顺、难度不合适，以及能靠一种打法反复通关的问题。游戏卡片中可以下载对应的试玩反馈模板，记录后发给分享游戏的人。

反馈时请尽量说明：游戏名称与版本、设备和浏览器、所在关卡，以及问题发生前的几步操作。能附截图或录屏会更容易复现。

## 更新网站

使用完整网站更新包时，先解压，再把「上传到GitHub」文件夹**里面的内容**上传到本仓库根目录，保留目录结构并覆盖同名文件。「维护源码」和外层使用说明留在电脑上即可。

完整网站包根目录的 `index.html` 是游戏屋首页；单独游戏下载包中的 `index.html` 是游戏本体，两者用途不同。

提交后等待 GitHub Pages 部署完成，再刷新网站。如果仍显示旧内容，可按 `Ctrl + F5` 强制刷新。现有网站的 Pages 配置保持不变。
